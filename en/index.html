The security of what you ship, measured where you are.

Asmolabs builds Vectispire: an application security posture platform that scans your repositories and container images and gathers what it finds into a single dashboard. The source is open, and the analysis never leaves your infrastructure.

Vectispire

Apache 2.0 Spring Boot · JDK 25 Angular PostgreSQL · MySQL

Vectispire scans Git repositories and container images, generates an SBOM, matches known vulnerabilities against it, and detects hardcoded secrets, problematic licences and infrastructure-as-code misconfigurations. Every finding is tracked over time: first seen, how often, whether a fix exists, and a triage decision expressed in the VEX vocabulary.

Every scanner runs in an ephemeral container, with the network cut and a read-only mount. Nothing about the code you scan leaves your machine — a property of the product, not a clause in a contract.

EPSS enrichment and the CISA KEV catalogue prioritise beyond the raw CVSS score, and the distinction between direct and transitive dependencies separates what you can fix this afternoon from what waits on an upstream release. Exports follow the software supply chain formats: CycloneDX 1.6 with embedded VEX, CSAF 2.0 and OpenVEX.

The product's other half answers a different question: what can you show. The estate is evaluated against six frameworks — NIS 2, DORA, ISO 27001, PCI-DSS, CRA, SOC 2 — deterministically. The statement of applicability sets what you declare about each control against what is measured, and puts the disagreements at the top. The certified scope, the exceptions granted, the CI gate's refusals and a hash-chained audit log come together in a dated, signed attestation: what the estate looked like, at an hour, with the proof attached.

What it looks at

Established tools, orchestrated — not rewritten. Every scanner image is pinned by digest, never by tag.

The six families of analysis and the tool that runs each.
AreaToolWhat comes back
Dependencies (SCA) syft → grype SBOM generation, then known-vulnerability matching
Secrets gitleaks API keys, tokens and credentials committed to the repository
Infrastructure as code checkov Terraform and Kubernetes misconfigurations
Source code semgrep Off by default; needs a rule set you install yourself
End of life endoflife.date Runtimes and distributions past their security support — a risk with no CVE attached
Licences From the SBOM Evaluated against a configurable blocklist
